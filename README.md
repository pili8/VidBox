# VidBox

抖音风格刷视频 Android App，支持自定义视频源。

## 版本

| 版本 | 分支 | 说明 |
|------|------|------|
| **v3.x** | `main` | 新增平铺模式（全屏 ↔ 2列网格一键切换） |
| **v2.x** | `v2` | 经典全屏模式，上下滑动切换视频 |

## 功能

### V3 - 双视图模式

同一个视频列表，两种查看方式：

- **全屏模式**：上下滑动，一个视频占满屏幕（同 V2）
- **平铺模式**：2 列网格，每个格子自动静音播放

### V2 - 经典模式

- 上下滑动切换视频（ViewPager2 + ExoPlayer）
- 单击暂停/播放
- 长按 1.5 秒下载（震动反馈）
- 默认静音，按钮切换
- 自定义视频源：添加/编辑/删除
- 视频源勾选启用，权重 1-9 加权随机
- 百分比实时显示
- 下载目录可设置
- 预缓冲下一个视频

## 技术栈

- Kotlin
- ViewPager2（垂直方向）
- Media3 ExoPlayer（视频播放）
- OkHttp（网络请求，处理 302 重定向）
- Gson（JSON 序列化）
- SharedPreferences（本地持久化）

## 构建环境

- JDK 17
- Android SDK 34
- Gradle 8.5
- 无需 root 权限

## 视频源格式

API 应返回：
- 直接返回 mp4 视频文件，或
- 302 重定向到 mp4 直链

默认无内置源，用户自行添加。
